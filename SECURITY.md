# Security policy

## Reporting

Report suspected vulnerabilities through GitHub private vulnerability reporting:

https://github.com/Liam-Soluxe/signoffkit/security/advisories/new

Do not include secrets, credentials, client-confidential material or regulated personal data in a public issue.

## Product boundary

SignoffKit is a browser-local beta. It has no server, account system, analytics or upload endpoint. Exported files are created on the user's device. File hashes demonstrate byte consistency only. They do not provide trusted timestamps, identity verification, electronic signatures, legal approval or compliance certification.

## Supported version

Only the latest public release is supported during beta.
