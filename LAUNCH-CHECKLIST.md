# Public launch checklist

- [x] Independent research agrees the problem is repeated and the beta remains sufficiently differentiated.
- [x] All functional tests pass.
- [x] Type checking passes.
- [x] Linting passes.
- [x] Production build passes.
- [x] Dependency audit has no high or critical findings.
- [x] Independent code review finds no blocking security or logic issue.
- [x] Mobile and desktop visual checks pass.
- [x] Demo, JSON round-trip and HTML export work in a real browser.
- [x] No secrets, credentials, client data, trackers or external APIs are present.
- [x] Privacy, terms and limitations are visible.
- [ ] GitHub repository is public and contains the source, README and licence.
- [ ] GitHub Pages workflow succeeds.
- [ ] Canonical HTTPS URL loads and the complete demo-to-export path passes live.
- [ ] Factory registry records the generic engine, version, owner and proof URL.
